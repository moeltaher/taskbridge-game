# No Boss

**الإصدار الحالي: v3.3.0**

لعبة ومحاكاة تدريبية عربية لفهم اقتصاد المنصات، والإدارة الخوارزمية، وتوزيع السلطة والأعباء، وشروط العمل، والوصول إلى الفرص في العمل الرقمي.

تضع اللعبة اللاعب داخل منصة افتراضية اسمها **No Boss**، ثم تنقله من تجربة العامل إلى دور الباحث. ويمكن أن تنتهي التجربة بورديّة عمل، أو مغادرة السوق دون قبول مهمة، أو رفض شروط الدخول ثم تحليل بوابة العقد نفسها.

المشروع تطبيق ثابت متعدد الصفحات يعمل على GitHub Pages، من دون backend أو API أو قاعدة بيانات أو إطار عمل مثل React/Vue. بيانات الجولة والأرشيف تحفظ محليًا في المتصفح فقط.

راجع [CHANGELOG.md](CHANGELOG.md) لتاريخ الإصدارات و[ARCHITECTURE.md](ARCHITECTURE.md) لتفاصيل البنية.

## ما تغير في v3.3

- اعتماد `STATE_SCHEMA_VERSION=4` وربط الجلسة الحية بإصدار التطبيق ونموذج الدرجة؛ الجلسات غير المتوافقة تُحذف كوحدة واحدة بدل خلط نتائج مشتقة من إصدارات مختلفة.
- حسم تعارضات تعدد التبويبات بترتيب حتمي يعتمد على revision ثم وقت الكتابة ثم معرّف الكاتب.
- تقليل الكتابة المتكررة إلى التخزين: نص الاستنتاج وشرائط خريطة السلطة تُحدث في الذاكرة أثناء الإدخال ثم تُحفظ عند نقطة آمنة.
- إعادة صياغة المسار غير البصري لمهمة البيانات ليقدم هندسة المشهد دون تكرار تسميات الإجابة الصحيحة حرفيًا.
- ربط حدث الأثر النفسي في مراجعة المحتوى بعينات إساءة/تهديد ظهرت فعلًا في المهمة المنجزة.
- إضافة حذف كامل لأرشيف الجولات وشرح أن النتائج محفوظة محليًا ولا ترسلها اللعبة إلى خادم.
- توضيح أن أسماء البلدان والمدن سياق سردي واجتماعي فقط، وأن اللعبة لا تحاكي القانون الوطني لأي دولة.
- توسيع فحوص axe الآلية لتشمل جميع مسارات العامل والباحث على Chromium وWebKit في سطح المكتب والموبايل.
- إزالة حقول حالة قديمة لم يعد لها استخدام، ومنها `powerDraft` و`reviewTaskScore`، مع منع إعادة إنشائها من الصفحات.

## الروابط المنطقية الحالية

`/scenario/`, `/onboarding/`, `/work/`, `/management/`, `/risk/`, `/dispute/`, `/payment/`, `/access/`, `/investigation/`, `/power/`, `/conclusion/`, `/result/`, `/rights/`.

كل مجلد صفحة في النسخة الحالية يقابله مسار موجود في route manifest؛ لا توجد صفحات runtime تاريخية منفصلة للإصدارات السابقة.

## بنية الصيانة

- `assets/js/core/` — الحالة، التخزين، المسارات، الواجهة، ونموذج الدرجة.
- `assets/js/domain/` — قواعد العمل، الإدارة، المخاطر، الاعتراض، الدفع، الوصول والتحليل.
- `assets/js/data/` — السيناريوهات، الأطراف، نموذج السلطة، مبررات المرجع، عينات العمل وهندسة مشاهد البيانات.
- `assets/js/pages/` — واجهات مراحل اللعبة الحالية فقط.
- `assets/css/` — التصميم والاستجابة.
- `tests/e2e/` — اختبارات Playwright والوصول.

ملفات HTML الخاصة بالمسارات مولدة من route manifest. بعد تغيير عنوان أو مسار أو إصدار:

```bash
node scripts/generate-pages.mjs
```

## التحقق قبل النشر

```bash
npm run check
npm run test:e2e
```

وتشمل الفحوص غير المتصفحية:

```bash
npm run check:routes
npm run check:structural
npm run check:regression
npm run check:domain
npm run check:semantic
npm run check:syntax
```

`check:semantic` يختبر الاتساق بين نموذج السلطة والأسئلة، مسار بلا عمل، المخاطر القائمة على الوقائع، توافق الحالة الحية، تكافؤ مساري مهمة البيانات، إزالة حقول الحالة القديمة، وحدود التقييم.

اختبارات المتصفح تعمل على Chromium وWebKit في إعدادات سطح المكتب والموبايل، وتشمل فحوص وصول آلية باستخدام axe عبر جميع المسارات الأساسية، إضافة إلى اختبارات لوحة المفاتيح والرحلات الكاملة.

## ملاحظة قانونية

المحاكاة أداة تدريبية لتحليل الوقائع وتوزيع وظائف السيطرة والأعباء، وليست حكمًا قانونيًا نهائيًا على توصيف علاقة العمل. أسماء الدول والمدن لا تعني تطبيق قوانينها داخل النموذج.
