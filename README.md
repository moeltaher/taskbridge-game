# No Boss

**الإصدار الحالي: v3.0.2**

لعبة ومحاكاة تدريبية عربية لفهم اقتصاد المنصات، والإدارة الخوارزمية، وتوزيع المخاطر، وشروط العمل، وعلاقات السلطة في العمل الرقمي.

تضع اللعبة اللاعب داخل منصة افتراضية اسمها **No Boss**، ثم تنقله من تجربة العامل إلى دور الباحث لتحليل كيفية توزيع المهام، وتحديد المقابل، وقياس الأداء، وإدارة الوصول إلى العمل، وتسوية النزاعات.

## ما الجديد في v3.0.2

- إزالة الوزن المزدوج لرفض العروض في ترتيب الوصول، مع فصل واضح بين مؤشر الوصول المرحلي وقرار التقييد أو التعليق النهائي.
- تحويل مؤشر الضغط إلى **حصيلة عبء وردية** تظهر في النتيجة النهائية، بحيث تصبح الاستراحة مفاضلة حقيقية بين الوقت والرفاه التدريبي.
- جعل الاعتراض على مراجعة الجودة قرارًا ذا تكلفة: وقت متابعة إضافي وارتفاع في عبء الوردية مقابل تخفيف عقوبة المؤشرات.
- إصلاح خريطة السلطة بحيث يتحدث مجموع النقاط مباشرة، وأي تعديل بعد اعتماد المحور يلغي اعتماده حتى يُعتمد من جديد.
- تعديل تصحيح خريطة السلطة ليعتمد على ترتيب الأطراف والأطراف الأكثر نفوذًا بدل مطابقة نسب رقمية دقيقة.
- جعل اختيار الأدلة في الاستنتاج اختياريًا ومنع منح نقاط أو فرض شروط شكلية لمجرد تحديد مربعات.
- توسيع التفسيرات المقبولة لدليل تحديد السعر، وتحسين وصولية تصنيف الأدلة والأسئلة وخريطة الحقوق.
- إضافة مقارنة فعلية للنتائج المحفوظة تشمل الدرجة والصافي والوقت وعبء الوردية والنتيجة النهائية للوصول.
- إضافة زر لحذف بيانات الجلسات القديمة بدل بقاء التحذير بصورة دائمة.
- توضيح أن جميع القيم المالية في المحاكاة بالدولار الأمريكي (USD)، وتصحيح عرض اسم العميل في اختيار الحالة.
- إصلاح توقيت إنشاء checkpoint حتى يظهر زر الرجوع بحالته الصحيحة عند دخول الصفحة.

## ما الجديد في v3.0.1

- فصل تخزين No Boss عن جلسات ونتائج TaskBridge القديمة.
- جعل القيم الابتدائية للحساب مختلفة حسب الشخصية.
- استبدال أمثلة مراجعة المحتوى وAI الملتبسة بأمثلة أوضح.
- إضافة بديل بلوحة المفاتيح لمهمة رسم الإطار.
- السماح بأكثر من تفسير مقبول لبعض الأدلة والأسئلة.
- إعادة بناء التسوية والوقت والتقييم وخريطة السلطة.

## ما الجديد في v3

- إعادة تسمية اللعبة والمنصة الافتراضية إلى **No Boss**.
- هوية بصرية وشعار جديدان.
- مراجعة شاملة لمنطق الوقت والمخاطر ومراجعة الجودة والتسوية والوصول.
- إضافة تعريف موسع بالهدف التدريبي للعبة في الصفحة الرئيسية.

المشروع يعمل بالكامل على GitHub Pages، من دون backend أو API أو قاعدة بيانات أو إطار عمل مثل React/Vue.

راجع [ARCHITECTURE.md](ARCHITECTURE.md) لتفاصيل الهيكل ومسؤولية كل ملف.

## التشغيل

افتح `index.html` عبر خادم ملفات ثابت أو GitHub Pages. بسبب استخدام JavaScript ES modules، يفضّل عدم فتح الملفات مباشرة ببروتوكول `file://`.

## الصيانة

- السيناريوهات والبيانات: `assets/js/data/scenarios.js`
- حالة اللعبة والتراجع: `assets/js/core/state.js`
- التخزين المحلي: `assets/js/core/storage.js`
- التوجيه والروابط: `assets/js/core/routes.js`
- كل مرحلة: `assets/js/pages/`
- CSS: `assets/css/`
- التحقق البنيوي: `scripts/check.py`

## ملاحظة قانونية

المحاكاة أداة تدريبية لتحليل الوقائع وتوزيع وظائف السيطرة، وليست حكمًا قانونيًا نهائيًا على توصيف علاقة العمل.
