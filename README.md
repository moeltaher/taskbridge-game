# خلف الشاشة: من يملك العمل؟ — TaskBridge

**الإصدار الحالي: v2.0.0**

لعبة/محاكاة تدريبية عربية عن العمل عبر المنصات، الإدارة الخوارزمية، الوقت غير المدفوع، توزيع المخاطر، وعلاقات السلطة في العمل الرقمي.

## ما الجديد في v2

أعيد بناء المشروع كـ **موقع متعدد الروابط ومنظم حسب المسؤولية** بدل ملف HTML واحد ضخم. لكل مرحلة منطقية رئيسية رابطها، بينما تُحفظ حالة اللاعب محليًا بين الصفحات.

المشروع ما زال يعمل بالكامل على GitHub Pages، من دون backend أو API أو قاعدة بيانات أو إطار عمل مثل React/Vue.

راجع [ARCHITECTURE.md](ARCHITECTURE.md) لتفاصيل الهيكل ومسؤولية كل ملف.

## الروابط المنطقية

`/scenario/`, `/onboarding/`, `/work/`, `/management/`, `/risk/`, `/dispute/`, `/payment/`, `/access/`, `/investigation/`, `/power/`, `/conclusion/`, `/result/`, `/rights/`.

## التشغيل

افتح `index.html` عبر خادم ملفات ثابت أو GitHub Pages. بسبب استخدام JavaScript ES modules، يفضّل عدم فتح الملفات مباشرة ببروتوكول `file://`.

## الصيانة

- السيناريوهات والبيانات: `assets/js/data/scenarios.js`
- حالة اللعبة والتراجع: `assets/js/core/state.js`
- التخزين المحلي: `assets/js/core/storage.js`
- التوجيه والروابط: `assets/js/core/routes.js`
- كل مرحلة: `assets/js/pages/`
- CSS: `assets/css/`

## ملاحظة قانونية

المحاكاة أداة تدريبية لتحليل الوقائع وتوزيع وظائف السيطرة، وليست حكمًا قانونيًا نهائيًا على توصيف علاقة العمل.
