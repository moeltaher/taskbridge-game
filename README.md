# خلف الشاشة | Behind the Screen

لعبة تدريبية تفاعلية باللغة العربية حول العمل في اقتصاد المنصات، الإدارة الخوارزمية، توزيع السلطة في علاقة العمل، والحقوق الاقتصادية والاجتماعية المرتبطة بالعمل الرقمي.

## التشغيل

افتح `index.html` مباشرة في المتصفح. لا تحتاج اللعبة إلى خادم أو قاعدة بيانات أو اتصال بالإنترنت بعد تحميل الصفحة.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع محتويات هذا المجلد إلى جذر المستودع، مع إبقاء `index.html` في المستوى الأعلى.
3. افتح: Settings → Pages.
4. تحت Build and deployment اختر: Deploy from a branch.
5. اختر الفرع `main` والمجلد `/(root)` ثم Save.
6. بعد اكتمال النشر سيظهر رابط الموقع في صفحة Pages.

عادةً يكون الرابط لمستودع مشروع بالشكل:
`https://USERNAME.github.io/REPOSITORY/`

## الخصوصية

اللعبة لا ترسل بيانات المشاركين إلى خادم. بعض الوظائف، مثل حفظ التقدم ونتائج المقارنة، تستخدم `localStorage` في متصفح المستخدم فقط.

## ملاحظات تقنية

- الموقع Static HTML/CSS/JavaScript.
- لا يستخدم AI أثناء التشغيل.
- لا يحتاج API أو Backend.
- ملف `.nojekyll` مضاف لمنع GitHub Pages من محاولة معالجة الموقع عبر Jekyll.

## الاستخدام التدريبي

هذه محاكاة تعليمية وليست أداة لإصدار توصيف قانوني نهائي لعلاقة العمل.
