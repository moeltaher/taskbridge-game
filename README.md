# No Boss

**الإصدار الحالي: v3.0.1**

لعبة ومحاكاة تدريبية عربية لفهم اقتصاد المنصات، والإدارة الخوارزمية، وتوزيع المخاطر، وشروط العمل، وعلاقات السلطة في العمل الرقمي.

تضع اللعبة اللاعب داخل منصة افتراضية اسمها **No Boss**، ثم تنقله من تجربة العامل إلى دور الباحث لتحليل كيفية توزيع المهام، وتحديد المقابل، وقياس الأداء، وإدارة الوصول إلى العمل، وتسوية النزاعات.

## ما الجديد في v3.0.1

- فصل تخزين No Boss v3 عن جلسات ونتائج TaskBridge القديمة لمنع خلط نماذج مختلفة.
- جعل القيم الابتدائية للحساب مختلفة حسب الشخصية مع توضيح أنها مدخلات تدريبية.
- استبدال أمثلة مراجعة المحتوى وAI الملتبسة بأمثلة أوضح.
- إظهار آثار الضغط الافتراضية بدل تغييرها في الخلفية.
- إضافة بديل بلوحة المفاتيح لمهمة رسم الإطار.
- السماح بأكثر من تفسير مقبول لبعض الأدلة والأسئلة عندما تكون الوقائع قابلة لذلك.
- إعادة توزيع الدرجة إلى: 30 لأسئلة العلاقة، 30 لتصنيف الأدلة، و40 لخريطة السلطة، من دون نقاط تلقائية لمجرد اختيار مربعات الأدلة.
- إعادة تصميم خريطة السلطة لتكون القيم مباشرة وقابلة للتحكم، مع تحقق صريح من مجموع 100.
- إعلان حدود مراجعة الجودة وقواعد التكاليف الافتراضية بصورة أوضح.
- تحديث كل عناوين HTML والهوية إلى No Boss v3.0.1.

## ما الجديد في v3

- إعادة تسمية اللعبة والمنصة الافتراضية إلى **No Boss**.
- هوية بصرية وشعار جديدان.
- مراجعة شاملة لمنطق الوقت والمخاطر ومراجعة الجودة والتسوية والوصول.
- تحسين دقة النتيجة النهائية وطريقة احتساب خريطة السلطة والأدلة.
- إضافة تعريف موسع بالهدف التدريبي للعبة في الصفحة الرئيسية.

المشروع يعمل بالكامل على GitHub Pages، من دون backend أو API أو قاعدة بيانات أو إطار عمل مثل React/Vue.

راجع [ARCHITECTURE.md](ARCHITECTURE.md) لتفاصيل الهيكل ومسؤولية كل ملف.

## التشغيل

افتح `index.html` عبر خادم ملفات ثابت أو GitHub Pages. بسبب استخدام JavaScript ES modules، يفضّل عدم فتح الملفات مباشرة ببروتوكول `file://`.

## الصيانة

- السيناريوهات والبيانات: `assets/js/data/scenarios.js`
- حالة اللعبة والتراجع: `assets/js/core/state.js`
- التخزين المحلي: `assets/js/core/storage.js`
- التوجيه والروابط: `assets/js/core/routes.js`
- كل مرحلة: `assets/js/pages/`
- CSS: `assets/css/`

## ملاحظة قانونية

المحاكاة أداة تدريبية لتحليل الوقائع وتوزيع وظائف السيطرة، وليست حكمًا قانونيًا نهائيًا على توصيف علاقة العمل.
