# No Boss

**الإصدار الحالي: v3.7.0**

لعبة ومحاكاة تدريبية عربية لفهم اقتصاد المنصات، والإدارة الخوارزمية، وتوزيع السلطة والأعباء، وشروط العمل، والوصول إلى الفرص في العمل الرقمي.

## ما تغير في v3.7

- تبدأ خريطة السلطة والعبء بلا توزيع افتراضي، ولا يكتمل أي محور بمجرد تحريك شريط؛ يجب اعتماد التوزيع صراحة قبل المتابعة.
- ارتفع `STATE_SCHEMA_VERSION` إلى 8 و`SCORE_MODEL_VERSION` إلى 7، وأزيل حقل الحالة القديم `powerTouched` لصالح `powerConfirmed`.
- أصبح معدل قبول العروض مبنيًا على سجل تدريبي سابق لكل شخصية ثم يضيف قرارات الوردية الحالية، بدل أن يستطيع قرار واحد تحويل المؤشر إلى 0% أو 100%.
- توضح الواجهة أن رفض العرض يمكن أن يؤثر في ترتيب الفرصة التالية عبر معدل القبول، وأن عدد الرفضات نفسه يبقى عاملًا مستقلًا في مراجعة الوصول النهائية.
- أصبحت أسباب الاعتراض مرتبطة بالإجابة القابلة للمراجعة نفسها؛ لا يظهر سبب اعتراض إلا إذا كانت وقائع المهمة تدعمه فعلًا.
- تظهر تغذية راجعة فورية بعد كل سؤال تشخيصي قبل بناء خريطة السلطة، مع بقاء هذه الأسئلة خارج الدرجة.
- أضيف فحص اتساق منظم للاستنتاج: يحدد اللاعب خلاصة السلطة والعبء بما يتفق مع الخريطة التي اعتمدها، من دون تقييم آلي للنص الحر.
- أصبحت احتمالات أحداث المخاطر التدريبية معلنة، مع توضيح أنها احتمالات للمحاكاة وليست تقديرات إحصائية للقطاع.
- صيغت تكاليف الإنترنت والكهرباء والجهاز بوضوح باعتبارها تكلفة مشاركة تدريبية ثابتة للجولة، لا استهلاكًا محسوبًا بالدقيقة.
- أصبح مبلغ مراجعة الجودة موصوفًا باعتباره مبلغًا ما زال محجوزًا عند لقطة نهاية الجولة، لا خصمًا نهائيًا مفترضًا.
- جرى تجديد كل route shell الحي لـGitHub Pages إلى v3.7.0، مع استمرار منع الملفات القديمة المحذوفة واكتشاف أي route shell يتيم.

## المسارات

`/scenario/`, `/onboarding/`, `/work/`, `/management/`, `/risk/`, `/dispute/`, `/payment/`, `/access/`, `/investigation/`, `/power/`, `/conclusion/`, `/result/`, `/rights/`.

هذه ملفات HTML مولدة ومطلوبة لـGitHub Pages؛ ليست نسخًا قديمة من منطق اللعبة. المصدر الوحيد للمسارات هو `assets/js/core/routes.js`، والمولد يحذف تلقائيًا أي route shell مولد يصبح يتيمًا.


## ملاحظة قانونية

المحاكاة أداة تدريبية لتحليل الوقائع وتوزيع وظائف السيطرة والأعباء، وليست حكمًا قانونيًا نهائيًا على توصيف علاقة العمل.
