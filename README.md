# خلف الشاشة | Behind the Screen

**الإصدار الحالي: v1.0.2**

لعبة تدريبية تفاعلية باللغة العربية حول العمل في اقتصاد المنصات، الإدارة الخوارزمية، توزيع السلطة في علاقة العمل، والحقوق الاقتصادية والاجتماعية المرتبطة بالعمل الرقمي.

## التشغيل

افتح `index.html` مباشرة في المتصفح. لا تحتاج اللعبة إلى خادم أو قاعدة بيانات أو اتصال بالإنترنت بعد تحميل الصفحة.

## النشر على GitHub Pages

1. ارفع ملفات المشروع إلى جذر المستودع، مع إبقاء `index.html` في المستوى الأعلى.
2. من GitHub افتح: **Settings → Pages**.
3. تحت **Build and deployment** اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/(root)` ثم **Save**.
5. سيعاد نشر الموقع تلقائيًا بعد كل Commit إلى الملفات المنشورة على فرع `main`.

## سجل الإصدارات

تفاصيل التغييرات موثقة في [`CHANGELOG.md`](CHANGELOG.md).

### v1.0.2 — تبسيط بنية النشر

أصبحت اللعبة الكاملة والمصححة موجودة مباشرة في `index.html`. لم يعد المشروع يستخدم `app.html` أو iframe لتشغيل اللعبة؛ يحتفظ GitHub بتاريخ النسخ السابقة عبر الـCommits.

### v1.0.1 — إصلاح تخطيط سطح المكتب

يعالج هذا الإصدار مشكلة ضغط وانزياح واجهة اللعبة على أجهزة الكمبيوتر واللابتوب، مع الحفاظ على تصميم الهاتف والمنطق التدريبي دون تغيير.

## الخصوصية

اللعبة لا ترسل بيانات المشاركين إلى خادم. وظائف حفظ التقدم ونتائج المقارنة تستخدم `localStorage` في متصفح المستخدم فقط.

## ملاحظات تقنية

- Static HTML/CSS/JavaScript.
- لا يستخدم AI أثناء التشغيل.
- لا يحتاج API أو Backend.
- `.nojekyll` مضاف للتوافق البسيط مع GitHub Pages.
- يدعم تخطيطات الهاتف والتابلت واللابتوب وسطح المكتب.

## الاستخدام التدريبي

هذه محاكاة تعليمية وليست أداة لإصدار توصيف قانوني نهائي لعلاقة العمل.
